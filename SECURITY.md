# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is currently supported with security updates.

## Reporting a Vulnerability

If you discover a security issue, please **do not** open a public issue.

Instead, report it privately by emailing: [INSERT SECURITY EMAIL]

Please include:
- A description of the vulnerability
- Steps to reproduce or a proof of concept
- Potential impact
- Any suggested fixes (if available)

We will acknowledge your report within 48 hours and aim to provide a fix as soon as possible.
We appreciate your help in keeping noct safe and secure.
